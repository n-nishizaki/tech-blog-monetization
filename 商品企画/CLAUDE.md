# 商品企画 CLAUDE.md

**責任**: 買い手が金を払う理由がある商品を市場に置くこと。オーナーの強みは品質担保の手段であり、商品設計の出発点ではない。

## 商品設計の原則

1. **買い手の検索行動から始める** — 商品名・タイトル・説明文は買い手の語彙で書く。「壁打ち」「構造化」は内部用語。
2. **具体的な成果物を入り口にする** — 「思考を整理します」ではなく、買い手が手に入るものを想像できるタイトルにする。
3. **プロセスで信頼を作る** — 出品ページにプロセスを見せることで「テンプレ対応ではない」と伝わる。
4. **商品の軽さを維持する** — 単発・テキスト非同期・スコープ明確・断れる構造。

## 出品ページの設計構造

```
タイトル → 検索に引っかかる＋「これだ」と思わせる（具体的な成果物）
プロセス → 「この人なら大丈夫だ」と安心させる（設計の進め方）
成果物  → 「これが手に入る」と購入を確定させる（納品物の明示）
実績    → 「この人は本物だ」と裏付ける（信頼の証拠）
```

## 設計の型（全商品共通）

1. ヒアリング → 2. 構造設計 → 3. 論点整理 → 4. 次の一歩
