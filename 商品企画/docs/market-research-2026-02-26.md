## 3. 競合の見せ方パターン

### タイトルで約束していること

| パターン | 例 | 効果 |
|---------|---|------|
| **ツール名＋動詞** | 「WordPressのご相談に乗ります」 | 検索に引っかかりやすい |
| **悩み→解決** | 「混沌とした状況を整理します」 | 共感で惹きつける |
| **資格・経歴＋対応範囲** | 「ITエンジニア歴20年が相談に乗ります」 | 権威で信頼を得る |
| **成果物明示** | 「業務フロー図を作成します」 | 何が手に入るか明確 |

### プロセスの見せ方
- **ヒアリング → 分析 → 提案** の3ステップが最多
- 売れているサービスは「進め方」を明示して安心感を与えている
- 「やらないこと」を書いてスコープを明確にしている出品者は少数（差別化ポイント）

### 価格帯の分布
- **エントリー**: 1,000〜3,000円（実績積み段階）
- **ボリュームゾーン**: 3,000〜5,000円（テキスト相談）
- **ミドル**: 5,000〜10,000円（ビデオチャット or 成果物あり）
- **ハイ**: 10,000〜30,000円（継続サポート or パッケージ）

### 差別化の現状
- 大半が「経歴」で差別化（年数、資格、企業名）
- 「思考の型」「フレームワーク」を前面に出す出品者はほぼいない
- 「AI × 壁打ち」の掛け合わせは非常に少ない
- 「やらないこと」を明示して安心感を出す設計は希少

## 4. 買い手の語彙

### 購入前に使う言葉（検索・相談文）
- 「何から手をつけていいかわからない」
- 「モヤモヤする」「漠然とした不安」
- 「正直、どう指示を出せばいいのか分からない」（AI関連）
- 「自分のケースでどう使えばいい？」
- 「壁打ち相手がほしい」
- 「このままで大丈夫か分からない」
- 「相談できる人がいない」

### 購入後のレビューに出てくる言葉
- 「頭がまとまりました」「すっきり整理できた」
- 「自分では考えつかなかったアイデアをいただいた」
- 「前向きになれた」「心のモヤモヤが晴れた」
- 「的確なアドバイス」「丁寧に壁打ちとまとめをしてくださった」
- 「コストパフォーマンス最高」
- 「やりたいことが明確になってきた」
- 「寄り添ってくれるようなお返事」

### 買い手が重視するポイント
- プロフィール・実績・レビューの確認（購入前のチェック行動）
- 「寄り添い型」か「アドバイス型」かのスタイル
- レスポンスの速さ
- NDA対応の有無（社内情報を出す場合）

## 5. 競合がやっていないこと（ギャップ）

| ギャップ | 説明 |
|---------|------|
| **思考の型を渡す** | 分析結果だけでなく「使った思考フレームワーク」を納品物にしている出品者はほぼいない |
| **ブログで思考過程を公開** | 出品ページの信頼裏付けとして外部ブログを活用している出品者は少数 |
| **AI差別化の明示** | 「ChatGPTとの違い」を説明文に盛り込む出品者はまだ少ない |
| **スコープの明確な限定** | 「やらないこと」を明示して買い手の不安を先回りする設計は希少 |
| **IT＋ビジネスの両面** | 技術相談は技術だけ、ビジネス相談はビジネスだけ。両面をカバーする出品は少ない |

## 6. 商品設計への示唆

### タイトル案（買い手の検索語 + 具体的な成果物）

現行:「混沌とした状況を構造化し次の一手を明確にします」

改善候補:
1. 「ITの悩みを整理し次にやることを明確にします」— 「IT」「悩み」「整理」が買い手の検索語
2. 「IT課題を構造化して打ち手をまとめます」— 「IT課題」「打ち手」で検索する層向け
3. 「モヤモヤしたIT課題を整理して次の一手を出します」— 「モヤモヤ」は買い手頻出ワード

### 価格帯
- **現行3,000円は適切**。ボリュームゾーン（3,000〜5,000円）の下限で、実績積み段階に合致
- 評価10件到達後に5,000円への値上げを検討
- ビデオチャットオプション追加時は+2,000〜3,000円が相場

### 差別化ポイント（競合がやっていないこと）
1. **「思考の型」の納品** — 分析結果＋使ったフレームワークを渡す（再利用可能性）
2. **ブログによる信頼裏付け** — 出品ページからブログ記事へ誘導し「この人の思考を事前に見られる」体験を作る
3. **ChatGPTとの差別化を明示** — 「一般論ではなく、あなたの状況に実体験ベースの型を適用」
4. **「やらないこと」の明示** — スコープを限定することで逆に安心感を与える

### 説明文の改善ポイント
- 「構造化」「思考OS」は内部用語 → 買い手の語彙「整理」「まとめ」「次にやること」に置き換え
- レビュー頻出語「頭がまとまった」「モヤモヤが晴れた」をサービス説明に織り込む
- 「ChatGPTに聞いたけど一般論しか返ってこない」は強い共感ポイント（現行v2で既に活用済み ✅）
