## サービス説明文

### 本文

**こんなお悩みはありませんか？**

- プロジェクトや事業が混沌としていて、何から手をつけるべきかわからない
- ChatGPTに聞いてみたけど、一般論しか返ってこなくてモヤモヤする
- 「この判断で合ってるのか？」を、技術がわかる人に壁打ちしたい
- AIを業務に取り入れたいが、自分のケースでどう使えばいいかわからない

**このサービスでやること**

あなたの状況をテキストで送っていただき、私が**実体験から磨いた思考の型**を適用して返します。

1. 状況ヒアリング（テキストでのやり取り）
2. 問題の構造化（何が起きていて、何が本当の原因か）
3. 論点の整理（今、何を決めるべきか）
4. 次の一歩の提示（具体的に何をすればよいか）

**お渡しするもの**
- あなたの状況に対する構造化された分析
- その分析に使った思考の型（他の場面でもご自身で使えます）

ChatGPTは一般論を返します。このサービスでは、15年の実務で検証してきた**特定の思考フレームワーク**をあなたの状況に当てはめます。

**やらないこと（ここが重要です）**

- ❌ コードを書く・実装する
- ❌ プロジェクトに常駐・継続参加する
- ❌ 成果を保証する
- ❌ 一般的なAIの使い方を教える（ググれば出る内容）

**こんな方に向いています**

- ITプロジェクトのPM・リーダーで、判断に迷っている方
- AIを導入したいが「自社の場合どうすれば？」がわからない方
- オフショア開発を検討中、または進行中で壁打ち相手がほしい方
- 技術選定や開発方針で悩んでいるエンジニア・マネージャー

**私の経験と思考の型の例**

- IT業界15年以上（Ruby, Python, AWS, Docker, Kubernetes等）
- オフショア開発5案件の実体験（成功も失敗も）
- 訴訟寸前のプロジェクトを構造化して立て直した経験あり
- 生成AIを日常業務に組み込んで活用中

ブログ「システム思考実践ノート」で、実際にどう構造化しているかを公開しています：
- 長期投資の判断 → 「感情と仕組みを分離する型」
- ポイント経済圏 → 「設計者の意図を読み解く型」
- オフショア開発 → 「失敗パターンから逆算する型」

これらの**思考の型を、あなたの状況に合わせて適用する**のがこのサービスです。

**進め方**

1. まずはお困りの状況をテキストで送ってください
2. 必要に応じて確認の質問をします（1-2往復）
3. 構造化した分析＋使った思考の型をお返しします
4. 回答に対する追加質問1回まで含みます

**納期**

ご相談内容を受領後、原則48時間以内に回答します。

## 受注時のオペレーション設計（オーナー用メモ）

### 受注から納品までの流れ

```
購入通知 → 内容確認（10分）→ 対応可否判断
  ├→ 対応可能 → Claude で下書き支援 → オーナーが構造化・編集（30-60分）→ 納品
  └→ 対応不可 → 丁寧にお断り＆返金（ココナラの仕組みで可能）
```

### 対応不可の基準（断ってOKなケース）

- 自分の経験領域から大きく外れる相談
- 実装作業や成果保証を求められた場合
- 情報が不足しすぎていて整理しようがない場合（追加ヒアリングしても不足の場合）

### Claudeの活用（受注後のワークフロー）

1. 相談内容をClaudeに投げて初期分析を作成
2. オーナーが自分の経験・知見を加えて構造化
3. 回答をClaudeで推敲・校正
4. オーナーが最終確認して納品

**ポイント**: AIだけで完結する回答はしない。オーナーの経験に基づく判断・視点が必ず入ること。

### 受注量コントロール

- 初期は同時受注1件まで
- 慣れてきたら2-3件まで拡大
- それ以上になったら出品を一時停止
- ココナラの「受付休止」機能を活用
