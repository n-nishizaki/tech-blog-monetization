# 構成案: 貯めるべきポイントと貯めるべきでないポイント

## 基本設計

**タイトル**: ポイントで得する人・損する人の構造的な違い【10年・38万ポイントの実体験】
**メインKW**: 楽天経済圏
**サブKW**: ポイ活 時間の無駄, 楽天ポイント 貯め方, ポイ活 効率
**ターゲット**: ペルソナ3「仕組み化で消耗を減らしたい人」
**想定文字数**: 4,000字
**アフィリエイト**:
- 楽天カード → Aセクション「改善策①」直後
- 楽天銀行 → Aセクション「改善策②固定費設定」直後
- 楽天証券 → Mセクション「ポイントの出口設計」直後

## STREAM構成

### S: ポイ活で時間を溶かすのをやめよう（〜250字）
→ 結論を冒頭で太字明示：「支払い方法を変えるだけで年24,000円が自動で積み上がる。広告クリックのポイ活は不要」
→ 読者の困りごと：広告を何十個クリックしても100ポイント…という時間浪費の場面
→ 「一度設定した楽天カードが10年で38万ポイントを生んだ」という結果を提示

### T: ポイントとお金は同じ価値なのに、なぜ使い方が変わるのか（〜350字）
→ レンズ：「ポイントと現金の心理的価値の非対称性」1本に絞る
→ 同じ1,000円の価値でも、ポイントは「泡銭」として軽く扱い、現金は慎重に使う——人間の認知の構造的な歪み
→ このレンズで見ると：ポイ活の失敗は「お得かどうか」ではなく「この心理的歪みをどう設計で修正するか」の問題
→ 図解：「同じ1,000円でも心理的重さが違う」天秤図（左：現金1,000円＝重い、右：1,000ポイント＝軽い）

### R: 「うまい話には裏がある」が、機会を逃させる（〜600字）
→ Tのレンズで2つの間違い構造を分解：
  - 間違い①「思考停止」：「うまい話には裏がある」で構造を読む前に拒絶 → 友人のPayPay・Kyash活用を見て企業構造を理解するようになった転換点
  - 間違い②「泡銭扱い」：ポイントを贅沢品に使いがち → 複利思考で「ポイントで必需品・現金で贅沢品」の設計が蓄財を加速
→ 数値：月20万円の支払いで決済の半分が現金なら年間ポイントも半分 → 年12,000ポイント分の機会損失

### E: 「一手間のサボり」が10年で24万円になる（〜300字）
→ 時間軸で可視化：年24,000ポイント × 10年 = 24万円分の機会損失
→ コミカルな例え話：「毎朝100円玉を道に落としながら歩いているが、落としていることに気づいていない」
→ 楽天経済圏の改悪への言及：「改悪が続いているがそれでも最強——仕組みを持つ人と持たない人の差は縮まらない」

### A: 設定3回、あとは10年間ほったらかしでいい（〜750字）
→ 原則を先に提示：「ポイントは必需品に・現金は贅沢品に」——心理的非対称性を逆用して蓄財加速
→ 改善策3つ（なぜ効くかの構造的説明とセット）：
  1. 楽天カードを作る → 設定型の起点。月20万円支払いが年24,000ポイントに変わる → [楽天カードリンク]
  2. 固定費（家賃・光熱費）をカード払いに変更する → 意識ゼロで積み上がる完全設定型。光熱費は楽天銀行カードが有利 → [楽天銀行リンク]
  3. 高還元カードを追わない → コンビニ・ファミレス限定高還元カードは管理コストが利回りを超える。「ポイントは必需品に」原則が守れなくなる
→ 最初の一歩：「今日楽天カードを申し込む」だけでOK

### M: 意識せず積み上がり続ける仕組みの完成（〜300字）
→ 出口設計まで含めたループ：楽天Pay（期間限定ポイント優先消費）→ 楽天証券の積立NISAでポイント自動投資 → ポイントが資産になる → [楽天証券リンク]
→ 新サービス導入時のルーティン：「ポイントが手に入る入口がないか確認する」を習慣化
→ 締め：「設定は3回だけ。あとは10年後も自動で積み上がり続ける」
