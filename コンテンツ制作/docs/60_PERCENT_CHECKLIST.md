## [構造的完全性]
- [ ] STREAM型の6要素が揃っているか（S, T, R, E, A, M）

## [証拠性]
- [ ] 実体験ベースの具体的な数値・エピソードが含まれているか

## [最低限の品質]
- [ ] タイトルに具体的な数値・結果が入っているか
- [ ] メタディスクリプションが120-160文字以内か
- [ ] 図解が最低1つ以上あるか
- [ ] 改善策が具体的で実践可能か（「〇〇すべき」だけでなく「どうやるか」まで）

## [禁止事項]
- [ ] 「〜かもしれません」「〜と思います」を使っていないか
- [ ] 過度な煽り表現を使っていないか
- [ ] 根拠のない断定をしていないか
- [ ] 論理矛盾がないか

## [文字数チェック] ⚠️ 必須
- [ ] **本文が目安の±20%以内に収まっているか**
  - 確認コマンド:
```python
python3 << 'EOF'
with open("[ファイルパス]", "r", encoding="utf-8") as f:
    lines = f.readlines()
    body = "".join(lines[9:])  # 10行目以降が本文
    print(f"本文: {len(body)} 文字")
EOF
```

## [STREAM構造の隠蔽] ⚠️ 必須
- [ ] **見出しに "S:", "T:", "R:", "E:", "A:", "M:" が残っていないか**
  - 確認コマンド: `grep -E "^##\s+(S:|T:|R:|E:|A:|M:)" [ファイル名]`
