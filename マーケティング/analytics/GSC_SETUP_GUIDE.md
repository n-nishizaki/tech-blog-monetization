## はじめに

Google Search Console (GSC) は、Google 検索でのブログのパフォーマンスを追跡・改善するための無料ツールです。

### GSC でできること

- 🔍 **検索パフォーマンス**: どのキーワードで検索されているか
- 📊 **表示回数とクリック数**: 検索結果での露出とクリック率（CTR）
- 📈 **検索順位**: 各キーワードでの平均掲載順位
- 🗂️ **インデックス状況**: Google に登録されているページ数
- 🐛 **エラー検出**: クロールエラーやモバイルユーザビリティの問題
- 🗺️ **サイトマップ管理**: sitemap.xml の送信と監視

### 所要時間
- **プロパティ追加**: 3分
- **所有権確認**: 3-5分
- **サイトマップ送信**: 1分
- **データ収集開始**: 数日〜2週間

## Step 1: Google Search Console にアクセス

### 1-1. ブラウザで開く

以下のURLにアクセスしてください：
👉 **https://search.google.com/search-console**

### 1-2. Googleアカウントでログイン

- Google Analytics で使用したのと**同じGoogleアカウント**でログイン
- 同じアカウントを使うと、後で連携が簡単になります

---

## Step 2: プロパティの追加

### 2-1. 初回アクセス時

「Google Search Console へようこそ」画面が表示されます。

**「今すぐ開始」** をクリック

### 2-2. プロパティタイプの選択

2つの選択肢が表示されます：

```
┌─────────────────────────────────┐
│ ドメイン                        │  ← 選択しない
│ example.com                     │
│ すべてのサブドメインとプロトコル│
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ URL プレフィックス              │  ← こちらを選択
│ https://example.com             │
│ 指定したURLのみ                 │
└─────────────────────────────────┘
```

**「URL プレフィックス」** を選択してください。

### 2-3. URLの入力

URL入力欄に以下を入力：
```
https://n-nishizaki.github.io
```

**重要**:
- ✅ `https://` を含める
- ✅ 末尾の `/` は付けない
- ✅ `www` は付けない（GitHub Pages のデフォルトドメインには不要）

**「続行」** をクリック

---

## Step 3: 所有権の確認

### 3-1. 確認方法の選択

「所有権の確認」画面が表示されます。

以下の方法から選択できます：

#### 推奨方法1: Google Analytics を使用（最も簡単）

すでに Google Analytics が設定されているため、この方法が最も簡単です。

**手順**:
1. **「Google アナリティクス」** タブをクリック
2. 自動的に確認が行われます
3. 「所有権を確認しました」と表示されたら完了

**✅ この方法が最も簡単なので、まずこれを試してください！**

---

#### 推奨方法2: HTMLファイル（Google Analytics で確認できない場合）

もし Google Analytics での確認ができない場合は、HTMLファイルをアップロードします。

**手順**:

1. **「HTML ファイル」** タブをクリック
2. 以下のような画面が表示されます：

1. この HTML 確認ファイルをダウンロードします
   [google1234567890abcdef.html]  ダウンロード

2. 確認ファイルを https://n-nishizaki.github.io/ に
   アップロードします

3. ブラウザで以下にアクセスして確認します

3. **「ダウンロード」** をクリックしてHTMLファイルを保存

##### 3-2-2. HTMLファイルを Claude に渡す

ダウンロードしたHTMLファイル（`google1234567890abcdef.html`）を Claude に教えてください。

**例**:
```

```

Claude が以下の作業を行います：
1. ファイルをブログリポジトリのルートに配置
2. Git コミット & プッシュ
3. デプロイ完了を確認

##### 3-2-3. 所有権の確認

Claude がファイルをアップロード後：

1. ブラウザで以下にアクセスして、ファイルが存在することを確認：
   ```
   https://n-nishizaki.github.io/google1234567890abcdef.html
   ```
2. GSC の画面に戻り、**「確認」** をクリック
3. 「所有権を確認しました」と表示されたら完了

---

#### 代替方法3: HTMLタグ（上記2つができない場合のみ）

**手順**:
1. **「HTML タグ」** タブをクリック
2. 以下のようなメタタグが表示されます：
   ```html
   <meta name="google-site-verification" content="XXXXXXXXXXXXXXXXXXXX" />
   ```
3. このタグを Claude に伝えてください
4. Claude がブログの `<head>` セクションに追加します

## Step 6: 動作確認

### 6-1. サイトマップの確認（即座）

1. GSC → **「サイトマップ」** をクリック
2. 送信したサイトマップのステータスを確認
3. 「成功しました」になっていればOK

### 6-2. ページのインデックス状況（数日後）

1. GSC → **「ページ」** をクリック
2. 「なぜページがインデックスに登録されないのか」セクションを確認
3. 以下のような表示があればOK:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

インデックス登録済み: 3 ページ
登録されていない: 0 ページ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 6-3. 検索パフォーマンス（1-2週間後）

1. GSC → **「検索パフォーマンス」** をクリック
2. 以下のデータが表示されればOK:
   - **合計クリック数**: 検索結果からのクリック
   - **合計表示回数**: 検索結果での表示
   - **平均CTR**: クリック率（クリック数 ÷ 表示回数）
   - **平均掲載順位**: 検索結果での平均順位

## トラブルシューティング

### ❌ 所有権の確認ができない（Google Analytics 方法）

**原因1**: Google Analytics と異なるアカウントでログインしている
**解決**: 同じGoogleアカウントでログインし直す

**原因2**: Google Analytics の設定がまだ反映されていない
**解決**: 24時間待ってから再試行、または「HTMLファイル」方法を使用

### ❌ 所有権の確認ができない（HTMLファイル方法）

**原因1**: HTMLファイルがアップロードされていない
**解決**: ブラウザで直接アクセスして確認
```
https://n-nishizaki.github.io/google1234567890abcdef.html
```

**原因2**: デプロイがまだ完了していない
**解決**: GitHub Actions で緑色のチェックマークを確認

**原因3**: ファイル名が間違っている
**解決**: GSC で表示されているファイル名と完全に一致しているか確認

### ❌ サイトマップが「取得できませんでした」エラー

**原因1**: サイトマップがまだ生成されていない
**解決**: ブラウザで直接アクセスして確認
```
https://n-nishizaki.github.io/sitemap.xml
```

**原因2**: robots.txt が Google をブロックしている
**解決**: robots.txt の内容を確認
```
https://n-nishizaki.github.io/robots.txt
```

期待される内容:
```
User-agent: *
Allow: /

Sitemap: https://n-nishizaki.github.io/sitemap.xml
```

**原因3**: sitemap.xml の形式が正しくない
**解決**: sitemap.xml をブラウザで開いてエラーがないか確認

### ❌ 2週間経ってもデータが表示されない

**原因1**: ブログへのアクセスが少ない
**解決**: 記事を追加し、SNSで共有してアクセスを増やす

**原因2**: まだインデックスされていない
**解決**: 「URL検査」ツールで手動インデックスをリクエスト
1. GSC 上部の検索バーにページURLを入力
2. **「インデックス登録をリクエスト」** をクリック

**原因3**: noindex タグが設定されている
**解決**: ブログのHTMLソースを確認し、以下がないことを確認
```html
<meta name="robots" content="noindex">
```

## 次のステップ

### 1. Google Analytics との連携

GSC と GA4 を連携すると、両方のデータを組み合わせて分析できます。

**連携手順**:
1. GA4 管理画面 → **「管理」**
2. **「Search Console のリンク」**
3. **「リンク」** をクリック
4. Search Console プロパティを選択
5. **「送信」**

### 2. URL検査ツールで手動インデックス

新しい記事を公開したら、すぐにインデックスさせるため：
1. GSC 上部の検索バーに記事URLを入力
2. **「インデックス登録をリクエスト」** をクリック
3. 通常1-3日でインデックスされる

### 3. 定期的な確認

以下を定期的にチェックすることをおすすめします：

**週次**:
- 検索パフォーマンス（新しいキーワード、CTRの変化）
- インデックス状況（エラーがないか）

**月次**:
- 主要キーワードの順位変動
- 人気ページのトレンド
- カバレッジレポート（エラーページの確認）

## セットアップ完了後のデータ活用

### 検索パフォーマンスの分析

**確認できるデータ**:
- どのキーワードで検索されているか
- 検索順位は何位か
- クリック率（CTR）はどのくらいか
- 改善の余地があるキーワードはどれか

**活用例**:
- 表示回数が多いがCTRが低い → タイトルを改善
- 順位が10-20位のキーワード → コンテンツを強化して上位を狙う
- 想定外のキーワードで検索されている → 新しい記事のネタにする

### SEO 改善のサイクル

```
1. GSC で検索パフォーマンスを確認
   ↓
2. 改善ポイントを特定
   ↓
3. 記事のタイトル・内容を改善
   ↓
4. 数週間後、変化を確認
   ↓
5. 繰り返し
```
