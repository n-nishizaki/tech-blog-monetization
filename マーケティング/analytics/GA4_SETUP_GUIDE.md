## はじめに

このガイドでは、Google Analytics 4 (GA4) をブログに導入する手順を説明します。

### GA4 でできること

- 📊 **アクセス解析**: 訪問者数、ページビュー数、滞在時間
- 🌍 **流入元分析**: Google 検索、SNS、直接アクセスなどの割合
- 📱 **デバイス分析**: PC、スマホ、タブレットの比率
- 📈 **リアルタイム**: 今この瞬間に何人が見ているか
- 🎯 **人気記事**: どの記事が一番読まれているか

### 所要時間
- **アカウント作成**: 5-10分
- **ブログへの設定**: 5分
- **データ収集開始**: 設定後すぐ（レポートは24時間後から）

（全てチェックを推奨 = Google からの改善提案が受けられる）

## Step 5: 測定ID（Measurement ID）の取得

### 5-1. ストリーム作成完了

ストリームが作成されると、以下の画面が表示されます：

```
ウェブ ストリームの詳細
━━━━━━━━━━━━━━━━━━━━━━━━
ストリーム名: Website
ストリームURL: https://n-nishizaki.github.io

G-XXXXXXXXXX    [コピー]
```

### 5-2. 測定IDをコピー

**測定ID** の右側にある **「コピー」** アイコンをクリック

📋 測定IDの形式:
```
G-XXXXXXXXXX
```
（G- で始まる10文字の英数字）

### 5-3. 測定IDを記録

コピーした測定IDをメモ帳などに一時保存してください。
次のステップで使用します。

**❗重要**: この測定IDは公開情報なので、セキュリティリスクはありません。

## Step 7: 動作確認

### 7-1. デプロイ完了を待つ

GitHub Actions でデプロイが開始されます。

**確認URL**: https://github.com/n-nishizaki/n-nishizaki.github.io/actions

- 通常1-3分で完了
- 緑色のチェックマークが表示されたら完了

### 7-2. ブラウザの開発者ツールで確認

1. ブログにアクセス: https://n-nishizaki.github.io/
2. ブラウザで **F12** キーを押す（開発者ツールを開く）
3. **「ネットワーク」** タブをクリック
4. ページをリロード（F5キー）
5. フィルタに「gtag」と入力
6. 以下のようなリクエストがあればOK:
   ```
   gtag/js?id=G-XXXXXXXXXX
   ```

### 7-3. Google Analytics でリアルタイム確認

1. Google Analytics 管理画面に戻る
2. 左メニューから **「レポート」** → **「リアルタイム」** をクリック
3. ブログにアクセスした状態で、リアルタイムユーザー数が **1** になればOK

**注意**: リアルタイムレポートは即座に反映されますが、詳細なレポートは24時間後から表示されます。

## Step 8: データ収集の開始

### 8-1. 初回データ収集

設定後、以下のデータが自動で収集されます：
- ページビュー数
- セッション数（訪問回数）
- ユーザー数（訪問者数）
- 平均セッション時間
- 直帰率
- 流入元（検索、SNS、直接アクセスなど）

### 8-2. データが見られるタイミング

| レポート | データ表示開始 |
|---------|--------------|
| **リアルタイム** | 設定後すぐ |
| **ユーザー属性** | 24時間後 |
| **トラフィック獲得** | 24時間後 |
| **ページとスクリーン** | 24時間後 |

### 8-3. 確認推奨日

- **1日後**: 初回データが溜まったか確認
- **3日後**: 流入元の傾向を確認
- **1週間後**: 人気記事ランキングを確認
- **1ヶ月後**: 月次レポートを作成

## トラブルシューティング

### ❌ リアルタイムレポートにユーザーが表示されない

**原因1**: デプロイがまだ完了していない
- GitHub Actions で緑色のチェックマークを確認

**原因2**: ブラウザキャッシュが残っている
- ブラウザで **Ctrl + Shift + R**（強制リロード）

**原因3**: 広告ブロッカーが有効
- 広告ブロッカーを一時的に無効にして確認

**原因4**: 測定IDが間違っている
- `_config.yml` の測定IDを再確認
- `G-` で始まる10文字の英数字か確認

### ❌ 開発者ツールでエラーが出る

**エラー例**:
```
Failed to load resource: net::ERR_BLOCKED_BY_CLIENT
```

**原因**: 広告ブロッカーが gtag.js をブロック
**解決**: 自分のブログを広告ブロッカーの例外リストに追加

### ❌ 24時間経ってもレポートが表示されない

**確認事項**:
1. リアルタイムレポートでユーザーが表示されるか
2. ブログへのアクセス数が十分か（最低10セッション以上）
3. データ保持設定が有効か

**データ保持設定の確認**:
1. GA管理画面 → **「管理」**
2. **「データ設定」** → **「データ保持」**
3. **「イベントデータの保持」** が **「14か月」** になっているか確認

## 次のステップ

### Google Search Console との連携

GA4 設定後、Google Search Console と連携すると：
- GA でどのキーワードで流入したかが分かる
- GSC でどのページがクリックされたかが分かる
- 両方のデータを組み合わせて分析できる

**連携手順**:
1. GA管理画面 → **「管理」** → **「Search Console のリンク」**
2. **「リンク」** をクリック
3. Search Console プロパティを選択
4. **「送信」**

### 目標（コンバージョン）の設定

収益化を目指す場合、以下を「コンバージョン」として設定:
- アフィリエイトリンクのクリック
- 特定ページへの到達（お問い合わせページなど）
- 外部リンクのクリック

### カスタムレポートの作成

以下のレポートを作成すると便利:
- 人気記事ランキング（週次）
- 流入元別のセッション数（月次）
- 新規ユーザー vs リピーター（月次）
