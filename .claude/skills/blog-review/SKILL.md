# blog-review: 60%完成基準チェック

対象ファイル: $ARGUMENTS

## 事前確認

チェックリストを読み込む:
- [コンテンツ制作/docs/60_PERCENT_CHECKLIST.md](../../コンテンツ制作/docs/60_PERCENT_CHECKLIST.md)
- [コンテンツ制作/docs/STREAM_FRAMEWORK.md](../../コンテンツ制作/docs/STREAM_FRAMEWORK.md)

## チェック手順

### Step 1: ファイル読み込み

対象ファイルを読み込んで全文を把握する。

### Step 2: 文字数カウント

front matter（---〜---）を除いた本文の文字数をカウントし、目安との乖離率を計算する。

```python
python3 << 'EOF'
with open("$ARGUMENTS", "r", encoding="utf-8") as f:
    content = f.read()

# front matterを除去
parts = content.split("---", 2)
body = parts[2] if len(parts) >= 3 else content
print(f"本文文字数: {len(body.strip())}字")
EOF
```

### Step 3: STREAM構造の隠蔽確認

見出しに "S:", "T:", "R:", "E:", "A:", "M:" が残っていないか確認:

```bash
grep -nE "^##\s+(S:|T:|R:|E:|A:|M:)" "$ARGUMENTS" || echo "STREAM構造の露出なし ✅"
```

### Step 4: 全項目チェック

60%完成基準の各項目を1つずつ評価して結果を出力する。
