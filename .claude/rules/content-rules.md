# コンテンツ制作ルール

## 核心原則
「実績の発信」ではなく「思考の軌跡」を残す。
「この人はこう考える人だ」という判断基準を読者に渡すことが信頼構築の本質。

## 記事作成ルール
- STREAM型フレームワーク必須（S→T→R→E→A→M）
- 実体験ベースの具体的数値・エピソード必須
- 「答え」だけでなく「どう考えたか」の思考過程を含める
- 文字数目安±20%以内
- STREAM構造は隠蔽（自然な日本語見出しに変換）
- 60%完成基準の全項目クリア必須

## 禁止事項
- 「〜かもしれません」「〜と思います」の多用
- 過度な煽り表現
- 根拠のない断定
- コピペ感のある定型文
